PREMIUM LAW FIRM WEBSITE TEMPLATE
=================================

Thank you for purchasing this website template.

This is a responsive bilingual law firm website template
designed for lawyers, attorneys, legal offices, and law firms.

--------------------------------------------------
FILES
--------------------------------------------------

index.html
Main website file.

legal-template.html
Additional legal content page.

README.txt
This documentation file.


--------------------------------------------------
HOW TO USE
--------------------------------------------------

1. Open index.html with any modern web browser.

2. To edit the website, open index.html with a
   text editor such as Acode, VS Code, Sublime Text,
   or another HTML editor.

3. Save your changes and refresh the browser.


--------------------------------------------------
EDITING WEBSITE INFORMATION
--------------------------------------------------

You can change the following information:

- Law firm name
- Lawyer name
- Lawyer title
- Phone number
- Email address
- Office address
- Social media links
- Website link
- Map link
- SEO title
- SEO description
- SEO keywords


--------------------------------------------------
LANGUAGE
--------------------------------------------------

The template includes:

Arabic
English

Use the language button in the website header
to switch between Arabic and English.

The selected language is saved automatically
in the browser.


--------------------------------------------------
THEME
--------------------------------------------------

The template includes:

Dark Mode
Light Mode

Use the theme button in the header to switch
between the two modes.

The selected theme is saved automatically
in the browser.


--------------------------------------------------
CONTACT FORM
--------------------------------------------------

The contact form included in this template works
in demonstration mode.

To receive real customer messages, connect the
form to an email service, form service, backend,
or your preferred form processing system.


--------------------------------------------------
MAP
--------------------------------------------------

Replace the map placeholder or map link with
your preferred Google Maps location.


--------------------------------------------------
SOCIAL MEDIA
--------------------------------------------------

Replace the placeholder social media links with
your own:

Facebook
Instagram
LinkedIn
X / Twitter
Website


--------------------------------------------------
SEO
--------------------------------------------------

The template includes basic SEO meta tags.

You should replace the default SEO information
with your own website information.

Recommended:

- Unique page title
- Unique meta description
- Relevant keywords
- Proper website content
- Search engine verification
- Sitemap
- Robots.txt
